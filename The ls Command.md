The `ls` Command

The `ls` command lists the contents of a directory. It's one of the most frequently used commands in Unix-like systems, showing you files and folders at a glance.

`ls` also supports flags that change how much detail is shown or how results are sorted.

`ls` is commonly used for:

- Viewing files in the current directory
- Checking file permissions and sizes
- Listing hidden files

## ls Command Format

```
ls -la /path/to/directory
```

## Common Flags

- `-l` — long format (permissions, owner, size, date)
- `-a` — show hidden files (dotfiles)
- `-h` — human-readable sizes (e.g., 1.2K, 3.4M)
- `-t` — sort by modification time
